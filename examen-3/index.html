Tabla de Programación Dinámica: $DP[i][w]$

Celda de la Solución Óptima Caso Base

Cada celda representa el valor máximo alcanzable considerando los primeros i objetos y una capacidad máxima de w. Las celdas resaltadas marcan la trayectoria de decisión óptima encontrada por el algoritmo.

Requisito 1

El Problema que se Desea Solucionar

Se seleccionó el problema clásico de optimización combinatoria: El Problema de la Mochila 0/1 (0/1 Knapsack Problem).

Definición del Problema:

Se dispone de una mochila con una capacidad máxima de transporte de peso $W$. Además, se tiene un conjunto de $n$ elementos $\{1, 2, \dots, n\}$, donde cada elemento $i$ posee un peso $w_i > 0$ y un valor o beneficio asociado $v_i > 0$.

El objetivo es determinar qué elementos incluir en la mochila para maximizar el valor total acumulado sin sobrepasar la capacidad de peso $W$.

Restricción 0/1: Cada elemento puede ser incluido a lo sumo una vez ($x_i = 1$) o ser excluido por completo ($x_i = 0$). No se permite fraccionar objetos ni repetir unidades indefinidas.

$$\max \sum_{i=1}^{n} v_i x_i \quad \text{sujeto a} \quad \sum_{i=1}^{n} w_i x_i \le W, \quad x_i \in \{0, 1\}$$
Requisito 2

El Algoritmo de Programación Dinámica Seleccionado

Se implementó el Algoritmo de la Mochila 0/1 mediante Tabulación (Bottom-Up).

Este problema cumple con las dos propiedades fundamentales que justifican el uso de Programación Dinámica:

  • 1. Subestructura Óptima: La solución óptima al problema general para $n$ objetos y capacidad $W$ contiene dentro de sí las soluciones óptimas a los subproblemas con menos objetos ($i < n$) y capacidades menores ($w < W$).
  • 2. Subproblemas Superpuestos: Un enfoque recursivo ingenuo evaluaría los mismos pares $(i, w)$ repetidas veces, derivando en una complejidad exponencial $O(2^n)$. Con Programación Dinámica, cada subproblema se resuelve una única vez y se almacena en una tabla bidimensional de tamaño $(n+1) \times (W+1)$, reduciendo la complejidad a tiempo pseudo-polinomial $O(n \cdot W)$.
Requisito 3

Definición del Estado o Subproblemas

El estado se modela mediante una matriz bidimensional denotada como DP[i][w]:

Definición Formal del Estado:

$$DP[i][w]$$

Representa el valor máximo posible que se puede obtener considerando únicamente un subconjunto de los primeros $i$ elementos (es decir, $\{1, 2, \dots, i\}$) disponiendo de una capacidad máxima de peso $w$.

Los rangos de las variables de estado son:

  • $i \in \{0, 1, 2, \dots, n\}$ (número de elementos considerados)
  • $w \in \{0, 1, 2, \dots, W\}$ (capacidad actual analizada)
Requisito 4

La Relación de Recurrencia Utilizada

Al considerar el elemento $i$ con peso $w_i$ y valor $v_i$, se evalúan dos situaciones posibles frente a la capacidad actual $w$:

$$DP[i][w] = \begin{cases} DP[i-1][w] & \text{si } w_i > w \\ \max\Big(DP[i-1][w], \; v_i + DP[i-1][w - w_i]\Big) & \text{si } w_i \le w \end{cases}$$

Explicación de las ramas:

  1. Si $w_i > w$ (No cabe): El peso del objeto excede la capacidad disponible $w$. Por lo tanto, no es factible incluirlo y el valor óptimo es el mismo que se tenía con los $i-1$ elementos previos: $DP[i-1][w]$.
  2. Si $w_i \le w$ (Sí cabe): Tenemos dos opciones válidas y elegimos la que brinde el mayor beneficio:
    • Opción A (No tomarlo): Mantener el valor óptimo de los $i-1$ elementos con la misma capacidad: $DP[i-1][w]$.
    • Opción B (Tomarlo): Sumar el valor del objeto actual $v_i$ al valor óptimo obtenido con los anteriores $i-1$ elementos en el espacio restante: $v_i + DP[i-1][w - w_i]$.

Reconstrucción del Conjunto Óptimo (Backtracking):
Para determinar qué elementos formaron la solución, se inicia desde la celda final $DP[n][W]$ y se retrocede: si $DP[i][w] \neq DP[i-1][w]$, el elemento $i$ fue seleccionado, se añade a la lista y se actualiza $w \leftarrow w - w_i$. Si son iguales, el elemento $i$ no fue seleccionado.

Requisito 5

El Manejo de los Casos Base

Los casos base corresponden a las situaciones iniciales triviales donde no es posible generar ningún valor:

$$DP[0][w] = 0 \quad \forall w \in [0, W] \qquad \text{y} \qquad DP[i][0] = 0 \quad \forall i \in [0, n]$$
  • Fila 0 ($i = 0$): Si no se dispone de ningún elemento para empacar, el beneficio total es $0$, sin importar cuánta capacidad tenga la mochila.
  • Columna 0 ($w = 0$): Si la capacidad de la mochila es $0$, no cabe ningún elemento con peso positivo, por lo que el beneficio acumulable es $0$.

En la implementación, esto se traduce en inicializar la primera fila y la primera columna de la matriz con ceros antes de iniciar el llenado iterativo.

Requisito 6

Implementación del Algoritmo

A continuación se presenta el código fuente en JavaScript que ejecuta el cálculo completo, estructurado según las etapas de inicialización, tabulación y reconstrucción: 

/**
 * Solución al Problema de la Mochila 0/1 mediante Programación Dinámica
 * @param {Array<{nombre: string, peso: number, valor: number}>} items - Lista de objetos
 * @param {number} W - Capacidad máxima de la mochila
 * @returns {Object} Resultado con valor óptimo, objetos y tabla DP
 */
function resolverMochila01(items, W) {
    const n = items.length;

    // 1. MANEJO DE CASOS BASE:
    // Creamos una matriz (n + 1) x (W + 1) e inicializamos todas las celdas en 0.
    // Esto cubre automáticamente dp[0][w] = 0 y dp[i][0] = 0.
    const dp = Array.from({ length: n + 1 }, () => Array(W + 1).fill(0));

    // 2. TABULACIÓN BOTTOM-UP USANDO LA RELACIÓN DE RECURRENCIA:
    for (let i = 1; i <= n; i++) {
        const pesoActual = items[i - 1].peso;
        const valorActual = items[i - 1].valor;

        for (let w = 1; w <= W; w++) {
            if (pesoActual > w) {
                // Caso 1: El objeto no cabe en la capacidad w
                dp[i][w] = dp[i - 1][w];
            } else {
                // Caso 2: El objeto cabe -> Máximo entre no tomarlo y tomarlo
                const sinObjeto = dp[i - 1][w];
                const conObjeto = valorActual + dp[i - 1][w - pesoActual];
                dp[i][w] = Math.max(sinObjeto, conObjeto);
            }
        }
    }

    // 3. RECONSTRUCCIÓN DE LA SOLUCIÓN ÓPTIMA (BACKTRACKING):
    const seleccionados = [];
    let wRestante = W;
    const celdasCamino = new Set();
    celdasCamino.add(`${n},${W}`);

    for (let i = n; i > 0; i--) {
        if (dp[i][wRestante] !== dp[i - 1][wRestante]) {
            // El objeto i fue incluido en la mochila
            seleccionados.push(items[i - 1]);
            wRestante -= items[i - 1].peso;
        }
        celdasCamino.add(`${i - 1},${wRestante}`);
    }

    const valorOptimo = dp[n][W];
    const pesoTotal = seleccionados.reduce((acc, item) => acc + item.peso, 0);

    return {
        valorOptimo,
        pesoTotal,
        capacidadMaxima: W,
        seleccionados: seleccionados.reverse(),
        tablaDP: dp,
        celdasCamino
    };
}

Análisis de Complejidad Asintótica

  • Complejidad Temporal: $\Theta(n \cdot W)$. Dos ciclos for anidados recorren la matriz de tamaño $(n + 1) \times (W + 1)$, realizando operaciones aritméticas y comparaciones en tiempo constante $O(1)$ por celda.
  • Complejidad Espacial: $\Theta(n \cdot W)$. Espacio en memoria requerido para almacenar la tabla de estados $DP$, permitiendo visualizar la matriz y reconstruir el conjunto exacto de objetos.
