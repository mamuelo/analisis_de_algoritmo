## 🚀 Acceso Rápido al Entregable Actual

### Examen #1: Planificador de Coworking

Para ejecutar el proyecto de este entregable, ingresa a su directorio y ejecuta los comandos correspondientes:

```bash
# 1. Ingresar a la carpeta del entregable
cd examen-1

# 2. Instalar dependencias
npm install

# 3. Ejecutar pruebas unitarias formales (19/19)
npm test

# 4. Iniciar el servidor local
npm run dev
```
